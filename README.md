# py-mini-kv
A minimalistic in-memory Key-Value store with basic JSON persistence.

## Features
- In-memory storage using Python dictionaries.
- Easy `set`/`get`/`delete` interface.
- Persistence to local disk via JSON.

## Usage
Run directly:
```bash
python main.py
```
